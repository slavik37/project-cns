# Квартира №6 — единая концепция v3

Семья: **2 взрослых + 2 девочки** · **38.4 м²** с лоджией

## Смотреть это

**[`index-v3.html`](index-v3.html)** — согласованная версия (один план + одна палитра)

`index-v2.html` и `index.html` оставлены как архив ранних черновиков.

## Почему v3

В v1/v2 планы и интерьеры расходились: разная геометрия комнат и разный стиль отделки.
В v3 всё строится от **одного эталонного плана** и палитры:

| Элемент | Значение |
|---------|----------|
| Стены | тёплый белый `#F7F4EF` |
| Акцент | шалфей `#7A9E88` |
| Дерево | светлый дуб |
| Текстиль | бежевый лён |

## Фиксированная планировка

1. **С/У 4.3** — без переноса стояков  
2. **Кухня-ниша** — под стеной санузла  
3. **Детская ~9** — бывшая кухня (кровать слева, стол у окна)  
4. **Гостиная-спальня ~12.5** — кровать справа, диван к ТВ, стол у кухни  
5. **Лоджия 4.1** — стол + шкафы
