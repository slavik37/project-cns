## Концепция

1. **Санузел 4.3 м²** — без переноса стояков  
2. **Кухня-ниша ~3.5 м²** — у санузла (мойка ближе к стоякам)  
3. **Детская ~9.0 м²** — бывшая кухня, окно сохраняется, двухъярусная кровать  
4. **Гостиная-спальня родителей ~12.5 м²** — сон + диван + стол на 4  
5. **Лоджия 4.1 м²** — утепление, кабинет, шкафы  
6. **Прихожая** — шкаф-купе 1800×600
