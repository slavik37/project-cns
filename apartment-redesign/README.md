# Квартира №6 — перепланировка 1к → 2к

Семья из 4 человек: родители + 2 девочки.  
Исходник: 1-комнатная квартира, **38.4 м²** (с лоджией), **34.3 м²** без лоджии, 1 этаж.

## Концепция

| Зона | Площадь | Было | Стало |
|------|---------|------|-------|
| Детская (2 девочки) | ~9.0 м² | Кухня 9.7 м² | Отдельная комната с окном |
| Гостиная-спальня родителей | ~12.5 м² | Комната 15.2 м² | Кровать + диван + обеденный стол |
| Кухня-ниша | ~3.5 м² | — | У санузла (мокрые стояки) |
| Санузел | 4.3 м² | без изменений | без изменений |
| Прихожая | ~5 м² | расширена зоной кухни | шкаф-купе + вход |
| Лоджия | 4.1 м² | холодная | кабинет + хранение |

## Почему так

1. **Детям нужна отдельная комната с окном** — бывшая кухня идеально подходит (~9 м², двухъярусная кровать).
2. **Кухня у санузла** — короткий перенос коммуникаций; на 1 этаже согласование обычно проще.
3. **Родители в большой комнате** — сон + гостиная + стол на четверых в одном объёме.
4. **Лоджия** добавляет рабочее место и хранение без сжатия жилых комнат.

## Согласование

Перенос кухни и изменение перегородок требуют согласования перепланировки.  
Санузел и несущие стены в этой концепции не трогаются.
